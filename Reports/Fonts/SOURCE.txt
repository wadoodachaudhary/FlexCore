The four original TTF faces were losslessly packaged as WOFF2 using fontTools.
No glyphs, advance widths or font names were modified. No Microsoft fonts are distributed.

ReportFontCatalog prefers an installed Calibri face; otherwise it uses Carlito,
the upstream metric-compatible alternative. This substitution is disclosed in
the report's runtime diagnostics. It does not promise identical GDI rasterization.
The same embedded faces are used for browser measurement, preview and offline HTML.
